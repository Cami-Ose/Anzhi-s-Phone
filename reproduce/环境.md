# 环境

## 机器

Ubuntu，或者 Windows 下装在 WSL2 里的 Ubuntu。

- **内存 16GB 起**，`mka bacon` 全量编要这么多。12GB 内存 + 32GB swap + ccache 20G 也出过包，慢，而且容易在中途被 OOM 打断。
- **磁盘留 400GB**：源码约 170GB，产物再加一百多 GB。
- WSL 的话在 `%USERPROFILE%\.wslconfig` 里给内存：`memory=16GB`。

## 源码放哪

放 WSL 内部的 ext4，比如 `/home/<你>/lineageos`。**不要放 `/mnt/` 下的 NTFS** —— 慢十倍，编译基本跑不动。

## 依赖包

```bash
sudo apt update && sudo apt install -y \
  bc bison build-essential ccache curl flex g++-multilib gcc-multilib \
  git git-lfs gnupg gperf imagemagick lib32ncurses-dev lib32readline-dev \
  lib32z1-dev libsdl1.2-dev libssl-dev libxml2-dev libxml2-utils \
  lz4 lzop pngcrush rsync schedtool squashfs-tools xsltproc zip \
  zlib1g-dev python3 python3-pip
```

Ubuntu 26.04 的包名和这份有出入，缺哪个补哪个。

## repo 工具

```bash
mkdir -p ~/bin
curl https://mirrors.tuna.tsinghua.edu.cn/git/git-repo -o ~/bin/repo
chmod +x ~/bin/repo
export PATH=~/bin:$PATH
```

## git 身份

编译系统会读，填个能用的就行：

```bash
git config --global user.name "你的名字"
git config --global user.email "you@example.com"
```

## 网络

- 国内直连 Google 源会被墙，`repo init` 和 `repo sync` 走清华 TUNA 镜像，配置见[源码.md](源码.md)。
- 设备闭源驱动那份 vendor 仓库要从 GitHub 拉，本地是挂着代理做的。

## ccache

编过一次之后强烈建议开，能省掉大半重复编译：

```bash
export USE_CCACHE=1
export CCACHE_DIR=$HOME/lineageos/.ccache
ccache -M 20G
```
