## 走完能得到什么

一张能开机、系统里带着安知系统服务和 Chat 界面的 ROM。

得不到什么：自触发唤醒的执行端、日记流程、天气数据源、防盗这几样代码在仓库里，真机还没接通。长期稳定性和首次开机时长也没测过。

刷机有风险，别拿主力机做。
