# 首次开机

开机等 5～10 分钟，然后插上手机按顺序核一遍。

```bash
adb devices                      # 能看到设备
adb shell getenforce             # Enforcing（--dev 编的会是 Permissive）
adb shell pm list packages | grep anzhi     # com.anzhi.os
adb shell ls -l /system_ext/priv-app/AnzhiOS/
```

APK 不在 `system_ext/priv-app/` 里，说明 `--deploy` 没把它放进树，或者刷机少了 `system_ext.img`。

## 让安知能连上网

两套独立的封杀策略，都要过。

Data Saver（流量节省）：

```bash
adb shell cmd netpolicy add restrict-background-whitelist com.anzhi.os
adb shell cmd netpolicy list restrict-background-whitelist | grep anzhi
```

Doze 白名单：

```bash
adb shell dumpsys deviceidle whitelist +com.anzhi.os
adb shell dumpsys deviceidle whitelist | grep anzhi
```

只做 Doze 不做 Data Saver 的话，手机一到户外省电模式网络就被掐。

## VPS 地址和令牌

**不在 ROM 里，也不该烤进去。** 在手机上的设置界面填一次，存在应用私有目录里。

开发期想临时补位可以用 `adb shell setprop`，但 `/system/build.prop` 世界可读，`getprop` 任何 app 都能调 —— 别把令牌留在那儿。

模型 key 同理，不放手机里。

## 出问题看日志

```bash
adb logcat -b events | grep avc        # SELinux 拒绝
```

对照着看：

| 日志里的词 | 意思 |
|---|---|
| `avc: denied` | SELinux 缺规则 |
| `ClassNotFoundException` | APK 没打进 ROM |
| `WebSocket 未连接` | 地址不对，或者对端没起 |
| `database locked` | SQLite WAL 没生效 |

编不过或者行为不对，去[踩坑.md](踩坑.md) 对一下。
