# 刷机

## 前提

- bootloader 已解锁。首次做一次：`adb reboot bootloader` → `fastboot flashing unlock`。**这会清掉手机上的数据。**
- 装好 `adb` / `fastboot`。Windows 侧另装 Google USB 驱动。
- 产物从 `out/target/product/bluejay/` 拷到一个文件夹。脚本默认读 `E:\AnzhiROM`，不是那儿就用 `-RomDir` 指过去。

## 用脚本

`scripts/flash_rom.ps1`，Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\flash_rom.ps1                 # 交互确认
powershell -ExecutionPolicy Bypass -File scripts\flash_rom.ps1 -Yes            # 免确认，仍会查解锁状态
powershell -ExecutionPolicy Bypass -File scripts\flash_rom.ps1 -DisableVerity  # 额外关掉 AVB 校验，改过 vendor 才用
```

它按这个顺序做：

1. **fastbootd 刷逻辑分区** —— system / system_ext / product / odm / vendor / vendor_dlkm / system_dlkm，产物里有哪个刷哪个
2. **回 bootloader 刷 boot 侧** —— boot / vendor_boot / dtbo / vbmeta
3. 重启，等 `sys.boot_completed=1`
4. `setprop persist.vendor.anzhi.api_url`（令牌不碰，由应用设置界面填）
5. 自检安知组件和权限管道：APK 在不在 `system_ext/priv-app/`、privapp allowlist、进程起没起、无障碍自启、通知助理默认值

没解锁、没进 fastboot、哪个分区刷失败，它都直接停手不往下走。刷逻辑分区失败不动引导，可以安全重试。

`rom/flash_anzhi.bat` 别用了 —— 7 月混编的产物，会 bootloop。`flash_rom.ps1` 就是来替它的。

## 手工刷

Linux 下没有这个 ps1，等价流程：

```bash
fastboot devices

# 逻辑分区，要在 fastbootd 下
fastboot reboot fastboot
fastboot wait-for-device
fastboot flash system system.img
fastboot flash system_ext system_ext.img
fastboot flash product product.img
fastboot flash vendor vendor.img
fastboot flash vendor_dlkm vendor_dlkm.img
fastboot flash system_dlkm system_dlkm.img

# boot 侧，回 bootloader
fastboot reboot bootloader
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash dtbo dtbo.img
fastboot flash vbmeta vbmeta.img

fastboot reboot
```

产物里只有 OTA zip 没有 img 时，走 recovery 的 sideload。

刷自己编的这批 img 不用 `fastboot flashall -w` —— 这台设备是 A/B slot 加动态分区，走上面两条流程。

## 别省分区

Pixel 6a 是 A/B slot + 动态分区，少刷一个的后果：

| 漏掉 | 会怎样 |
|---|---|
| `vendor.img` | system 调 HAL 接口对不上，服务 crash |
| `product.img` | 部分系统服务缺失 |
| `system_ext.img` | **安知 APK 就装在这个分区**，等于没刷 |
| `vendor_dlkm` / `system_dlkm` | 内核模块不全，功能零星坏 |
| `vbmeta` | AVB 校验失败，开机红字警告或 bootloop |

## 刷完

首次开机要几分钟。脚本最多等 4 分钟，等到超时会停手让你先看日志，别急着重刷。

跨大版本升上来起不来，多半是旧数据不兼容，可以在 recovery 里清一次数据。

开机之后按[首次开机.md](首次开机.md) 核一遍。

## 起不来就重刷

刷完黑屏或者卡住，按住 音量下 + 电源 10 秒强制重启，还能看到 fastboot 界面，就重新走一遍上面的流程。
